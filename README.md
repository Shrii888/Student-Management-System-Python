# Student Management System

## Overview

A beginner-friendly Python project designed to manage student records.

## Features

- Add students
- Display students
- Search students by ID
- Update student records
- Delete students
- Calculate average marks
- Save and load records using JSON

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- JSON
- File handling

## How It Works

The program uses a list of dictionaries to store student records.

Each student record contains:

- Student ID
- Name
- Age
- Course
- Marks

The records are stored permanently in a JSON file.
